Check the offer in four steps

  1. Copy the exact code without adding spaces.
  2. Open Temu and use the account and delivery region you intend to order with.
  3. Follow the entry instructions on the offer page. Do not assume every code belongs in the same field.
  4. Review eligible items, minimum spend, expiry, any discount cap and the final payable total before payment.

For a fuller walkthrough, see how to use Temu promo codes. If the code is rejected, start with the troubleshooting guide.

New account or returning shopper?

A first visit, a new app installation and a first order are different things. The wording of the specific offer decides what qualifies. Returning customers should not assume a code advertised for new users will apply to them. Our new-user vs existing-user guide explains what to look for without promising eligibility.
